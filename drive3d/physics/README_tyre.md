# 4 輪のタイヤの滑り（v33）

`tyre5.js`（`HW.TY5`）は、走行中の横の運動を 4 輪それぞれのタイヤの力から計算し直す。
`patch_tyre5.py` がゲームの走行計算（従来の「限界の横加速度 → アンダー/オーバー」の直後）に差し込む。

## 計算していること（毎コマ、1/360 秒刻みの小さな段に分けて積分）

| 項目 | 内容 |
|---|---|
| すべり角 | 各輪の速度の向き（車体の横すべり速度 + ヨーレート × 位置）と、タイヤの向き（舵角）の差。緩和長で遅れて立ち上がる |
| 横力 | Magic Formula 型 `Fy = −Fymax·sin(C·atan(Bα))`。B はコーナリングの硬さから |
| 荷重 | 静的配分 + 前後の荷重移動（加減速）+ 左右の荷重移動（ロール剛性配分・ロールセンター・ロールの遅れ）+ 空力 |
| 荷重感度 | 荷重が大きいほど μ が下がる（外輪に荷重が集まると軸の合計グリップが減る） |
| キャンバー | ロールで外輪が起きるぶん |
| 温度 | 各輪の滑りの仕事 → 平均からのずれ |
| 摩擦円 | 縦の力（駆動・制動、縦のタイヤの計算の結果）を使った割合で横の最大が減る（楕円）。空転・ロックでさらに落ちる |
| LSD | 駆動力を荷重の大きい側へ配る |
| ABS / EBD | 曲がりながらのブレーキは、舵で求めている横の量とすべり角に応じて制動力を抑える。後輪は荷重で使える量の 7 割まで |
| ESC | 横すべりが大きいと片側にブレーキをかけてヨーを戻す（装備車のみ） |
| 運動 | 横すべり速度とヨーレートを、横力の合計とヨーモーメントから解く。β が 50° を超えるとスピン（事故の挙動へ渡す） |
| 運転者の修正 | アンダーステア勾配ぶんの舵の足し（縦の力による変化も）、後ろが流れたときのカウンターステア（自動運転は強く、手動は補助として弱く） |

## 確認（ヘッドレス Chromium、`tests/`）

- `lap_autopilot.js`: 富士、自動運転（アタック）。スープラ 60fps 116.6 秒 / 20fps 117.3 秒（従来 109.3 秒）、スピン・コース外 0。
  GT-R 110.6・GR86 120.2・NSX 118.4・シビック 116.6 秒、いずれも事故 0
- `steer_gain.js`: 一定の速度・ハンドル量での「狙った横加速度に対する実際の横加速度」の比。0.97〜1.07（25〜35m/s）。45m/s では 1.0〜1.2（やや曲がりすぎ）
- `steer_gain_brake.js`: 同じ条件でブレーキを踏んだとき（摩擦円で横は 0.3〜0.6 に下がる）
- `manual_wot.js`: 手動で切ったまま全開
- 実行: `THREE=/path/to/three.min.js node tests/harness.js ../index.html tests/lap_autopilot.js`

従来より周回が約 6% 遅いのは、曲がりながらの全力ブレーキが摩擦円で制限されるようになったため（従来は全力の制動と横の力を同時に出していた）。

切り替え: `localStorage.setItem('hw.ty5','0')` または URL に `?ty5=0` で従来の計算。

## 改良（前後バランス・直線の安定）と既知の問題

- **定常のアンダーステア**: 後輪の単位荷重あたりの横剛性を前輪より 35% 高くした（従来は 6%）。Supra で約 0.3°/G → 約 1.1°/G。駆動で後輪の横の力が落ちても、まだアンダーステアに残るようにした。
- **横剛性の扱い**: 摩擦円で縦に使った分は、横の「ピーク」（Fymax）だけを減らし、初期の横剛性は減らさない。
- **舵の合わせ込み（トリム）を削除**: 高速域で振動を起こしていた（GT-R の 400km/h 超の直線で 4 回中半数が暴走）。
- 試験（ヘッドレス Chromium）: 富士 1 周（スープラ、自動運転）114.2〜114.7 秒（60/20fps）、事故 0。サーキットのレース（NPC 11 台、90 秒）：接触 0、スピン 0。ドラッグ（400m・1000m の Supra、4000m の GT-R）：安定。
- **既知の問題**: 魔改造の Supra を 400km/h 超の長い直線（drag4000・drag10000）で走らせると、自動運転で横に振動して壁に当たることがある（試験では 4 回中 3 回が暴走）。高速域で横の動きが遅れ、ゆっくり振動するためで、補正ゲインを変えても直らなかった。GT-R（4WD）は安定。
- **定常のステアリングの効き**: 切った量に対する横加速度の比は、速度が上がると 0.93〜1.70 になった（従来 0.97〜1.23）。速度が高いほど、少しの切り込みで曲がりすぎる傾向。

試験スクリプト（`tests/`）: `drag_autopilot_stats.js`（ドラッグの自動運転の暴走の回数）、`steering_step.js`（ハンドルを一定量切ったときの向きの変化、速度別）、`no_steer_fast.js`（ハンドルを切らない高速直線）、`lateral_perturbation.js`（1m ずらしたあとの戻り方）。
